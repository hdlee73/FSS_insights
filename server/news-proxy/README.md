# 뉴스 프록시 (네이버 키를 서버 뒤에 두기)

앱은 이 서버에만 요청하고, 네이버 키는 서버 비밀값으로만 보관합니다. 앱·APK·GitHub 소스에는 키가 들어가지 않습니다.

## 한 번만 설정
GitHub 저장소 → Settings → Secrets and variables → Actions 에서:

| 종류 | 이름 | 값 |
|---|---|---|
| Secret | `CLOUDFLARE_API_TOKEN` | Cloudflare API 토큰(Edit Cloudflare Workers 템플릿) |
| Secret | `CLOUDFLARE_ACCOUNT_ID` | Cloudflare 계정 ID |
| Secret | `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | 네이버 개발자센터 키 |
| Secret | `NEWS_PROXY_TOKEN` | 앱과 서버가 공유하는 임의의 긴 문자열(직접 만들어 입력, 예: 영문·숫자 40자) |

1. Actions → **Deploy news proxy** → Run workflow. 실행 요약(Summary)에 `NEWS_PROXY_URL`이 표시됩니다.
2. 그 주소를 Variables에 `NEWS_PROXY_URL` 이름으로 저장합니다.
3. 앱을 다시 빌드(Android build)하면 네이버 검색이 기본으로 동작합니다. 서버가 없으면 앱은 Google 뉴스로 대신 검색합니다.

## 참고
- 앱 토큰은 APK 안에 들어 있어 완전한 비밀은 아닙니다. 네이버 API의 일일 호출 한도(25,000건)가 남용의 상한이며, 필요하면 토큰을 바꿔 다시 배포하세요.
- 같은 검색어는 2분간 서버 캐시를 사용합니다.

## 자료실(구글 드라이브) 연결 (v0.9.0)
드라이브에 올린 참고자료를 앱의 **참고 자료실** 탭에서 목록으로 보고 내려받게 합니다. 파일은 드라이브에 그대로 두고, 서버는 읽기 전용으로 중계만 합니다.

1. 드라이브에 자료실용 폴더를 만들고(하위 폴더 가능) **공유 → 일반 액세스 → "링크가 있는 모든 사용자(뷰어)"** 로 설정합니다. 파일은 이 폴더 안에 올리면 됩니다.
2. 폴더 주소(`drive.google.com/drive/folders/`**여기부분**)의 뒷부분이 폴더 ID입니다.
3. [Google Cloud 콘솔](https://console.cloud.google.com) → 프로젝트 만들기 → *API 및 서비스* → **Google Drive API 사용** → *사용자 인증 정보* → **API 키** 만들기. (키 제한에서 API를 Drive API로만 제한하는 것을 권장)
4. GitHub Secrets에 추가: `GOOGLE_API_KEY`(위 API 키), `GDRIVE_FOLDER_ID`(폴더 ID).
5. Actions → **Deploy news proxy** 다시 실행.

### 제목·설명·태그 붙이기
- **제목** = 드라이브 파일 이름, **설명** = 파일 우클릭 → 세부정보(ⓘ) → 활동/세부정보의 *설명*, **태그** = 설명 안에 `#검사 #자산운용`처럼 적은 해시태그입니다. 앱의 검색창은 이름·설명·태그에 더해 파일 본문까지 찾고(아래 *본문 검색* 참고), `#태그`로 검색하면 그 태그가 달린 파일만 나옵니다.
- 새 파일은 1분 안에 앱에 반영됩니다(서버가 1분간 목록을 기억).

### 본문 검색
- 별도 설정 없이 동작합니다. 구글 드라이브가 PDF·구글 문서·워드·엑셀·파워포인트·텍스트(스캔 PDF·이미지는 문자 인식 포함)를 자동으로 색인해 두므로, 서버가 드라이브 `fullText` 검색을 자료실 폴더 안으로 한정해 호출합니다. 본문에서만 찾은 결과에는 앱에 「본문 일치」가 표시됩니다.
- 한계: 한글(HWP)·압축 파일은 색인되지 않고, 새로 올린 파일은 드라이브가 색인할 때까지 수 분~수 시간 걸릴 수 있으며, 단어 일부(조사 앞부분 등)만으로는 일치하지 않을 수 있습니다. 본문 검색이 실패하면 제목·설명·태그 결과만 보여 줍니다.

### 운영 메모
- 폴더에 올린 파일은 링크를 아는 누구나 볼 수 있는 상태가 됩니다. 비공개 자료는 올리지 마세요.
- 서버는 지정한 폴더와 그 하위 폴더의 파일만 내줍니다. 구글 문서·슬라이드는 PDF, 스프레드시트는 엑셀로 변환되어 내려갑니다.

## 자료 올리기 제거
앱에서 파일을 올리는 기능과 서버의 `/library/upload` 경로는 제거했습니다(참고 자료실은 조회·내려받기 전용). 파일은 구글 드라이브 폴더에 직접 올립니다. 예전에 설정한 Apps Script 웹앱 배포와 GitHub Secrets `APPS_SCRIPT_URL`·`APPS_SCRIPT_SECRET`, Cloudflare Worker의 같은 이름 비밀값은 더 쓰지 않으므로 지워도 됩니다.

## 국내 금융 통계(한국은행 ECOS)
시장동향 탭의 "국내 금융 통계"(기준금리, 국고채 3·10년, CD 91일, 회사채 AA-, 가계신용, 은행 가계대출·연체율·대출금리, 외환보유액)를 서버 `/stats`가 중계합니다.

1. [ECOS Open API](https://ecos.bok.or.kr/api/) 인증키를 발급받아 GitHub Secrets에 `ECOS_API_KEY`로 저장합니다.
2. Actions → **Deploy news proxy** 다시 실행.

통계표·항목 코드는 ECOS 통계표/항목 목록에서 확인한 값을 `STAT_SPECS`에 적어 두었습니다(기준금리·외환보유액만 이름 키워드로 찾음). 앱은 `/stats?ids=ktb-3y,corp-aa,…`처럼 사용자가 고른 통계만 요청하고, `ids`가 없으면 기본 묶음(`DEFAULT_STAT_IDS`)을 돌려줍니다. 못 찾은 항목은 화면에서 빠지며, 응답의 `missing`에 id가 남습니다. 결과는 조합별로 1시간 캐시됩니다.

통계를 추가하려면 `STAT_SPECS`에 한 줄을 더하고(앱의 `STAT_CATALOG`에도 같은 id를 추가), **Deploy news proxy**를 다시 실행하세요. 앱만 새로 설치하고 서버를 다시 배포하지 않으면 새로 늘린 통계는 표시되지 않습니다.

## 금융사 주요 경영정보(FISIS)
앱의 **금융사 주요 경영정보** 화면은 금융통계정보시스템(FISIS) Open API를 서버(`/fisis/*`)로 중계합니다. 인증키는 서버 비밀값으로만 보관합니다.

1. [FISIS Open API](https://fisis.fss.or.kr/page/api-key.jsp)에서 인증키를 신청합니다(무료).
2. GitHub Secrets에 `FISIS_API_KEY`로 저장하고 Actions → **Deploy news proxy**를 다시 실행합니다.
- 권역: 증권사(F, 선물사 W를 합쳐서 표시), 자산운용사(G), 은행(A), 생명보험(H), 손해보험(I), 저축은행(E), 카드사(C). 이름 끝에 `[폐]`가 붙은 폐업 회사는 제외합니다.
- Worker는 한 번의 호출에 하위 요청(외부 호출·캐시 포함)을 50건까지만 보낼 수 있습니다. 그래서 **배포할 때** `build-fisis-data.mjs`가 권역별 회사 목록, 총자산 순위, 통계표·계정 위치를 FISIS에서 미리 받아 `fisis-data.json`으로 만들어 서버에 함께 올립니다(수 분 걸립니다). 서버는 이 자료로 목록·순위를 바로 돌려주고, 회사 상세만 통계표 몇 개를 실시간으로 받습니다.
- 통계표 번호를 코드에 박지 않고 FISIS 통계목록·계정항목에서 통계표·계정 **이름**으로 총자산·총부채·BIS비율 등을 찾습니다. 어떤 통계표·계정을 쓰는지는 `GET /fisis/spec?sector=A`(앱 토큰 필요)로 확인할 수 있고, 앱 화면에도 항목마다 출처가 작게 표시됩니다.
- 총자산 순위는 배포 시점 기준입니다. 분기 자료가 새로 나오면 Deploy news proxy를 다시 실행하면 갱신됩니다. FISIS 일일 호출 한도에 걸리면 이미 만든 권역만 갱신합니다.
- 계정 이름은 앞 번호·공백을 떼고 견주므로 "자산총계", "자산 총계", "Ⅰ. 자산총계" 같은 표기 차이를 모두 잡습니다. 후보가 여럿이면 배포할 때 표본 회사 6곳으로 실제 값이 나오는 계정만 확정하며, 선택 결과는 Deploy 로그의 `[권역] fin/ratio …` 줄에 남습니다. 금액은 모두 억원으로, 비율은 %로 환산해 앱에 보냅니다.
- 대표이사·최대주주 등 FISIS에 없는 자료는 다루지 않습니다(OpenDART 연동은 제거했습니다).

## 스마트 법령검색 (/law)

앱의 "스마트 법령검색" 메뉴는 국가법령정보 공동활용 Open API(DRF)를 이 서버를 거쳐 호출합니다. 인증값(OC)은 앱에 넣지 않고 서버 비밀값으로만 둡니다.

1. [국가법령정보 공동활용](https://open.law.go.kr/LSO/openApi/guideList.do)의 **API인증키 관리** 화면에서 '현재 API인증키(OC)' 값을 확인합니다(로그인 아이디가 아닙니다).
2. GitHub Secrets에 `LAW_OC`로 저장하고 Actions → **Deploy news proxy**를 다시 실행합니다.

`LAW_OC`가 없으면 `/law`는 503을 돌려주고 앱은 오류를 표시합니다(서버 주소가 없는 빌드는 데모 데이터로 동작).

## 기업 개황 및 공시(DART)
앱의 **기업 개황 및 공시(DART)** 화면은 DART 전자공시 Open API(기업개황, 최대주주 및 특수관계인, 재무손익, 정기보고서, 주요사항보고서, 기타공시)를 서버(`/dart/*`)로 중계합니다. 주가는 앱이 시장지표와 같은 시세 제공처에서 직접 받습니다.

1. [DART Open API](https://opendart.fss.or.kr)에서 인증키를 발급받습니다(무료).
2. GitHub Secrets에 `DART_API_KEY`로 저장하고 Actions → **Deploy news proxy**를 다시 실행합니다.
- DART에는 회사명으로 고유번호를 찾는 API가 없어서, **배포할 때** `build-dart-data.mjs`가 고유번호 목록(corpCode.xml)을 받아 상장사와 2023년 이후 이력이 있는 비상장사만 추려 `dart-corps.json`으로 만들어 서버에 함께 올립니다. 회사 검색은 이 목록으로 합니다.
- 최대주주 및 특수관계인은 가장 최근 정기보고서(분기·반기·사업) 기준으로 찾습니다. 공시 목록은 정기(A)·주요사항(B)·기타(발행 D, 지분 E 등, 거래소 I)로 나누어 최근 것부터 보여 줍니다. 시장 구분(유가증권·코스닥·코넥스·기타법인)은 검색할 때 DART 기업개황의 법인구분으로 정합니다.

## 익명 사용 통계(일일 핑)와 관리자 화면
앱이 하루 한 번 `POST /usage/ping`으로 (무작위 설치 ID, 앱 버전, 날짜, 날짜별 메뉴 이용 횟수)만 보내고, Worker가 Cloudflare **D1**(`fss-usage`)에 저장합니다. 설치 ID는 `SHA-256(설치ID:APP_TOKEN)`으로 해시해 저장하고 IP·기기정보는 저장하지 않습니다. 앱 정보 화면에서 사용자가 끌 수 있습니다.

1. GitHub Secrets에 `ADMIN_TOKEN`(앱 토큰과 다른 임의의 긴 문자열)을 저장합니다. Cloudflare API 토큰에는 **D1 편집(Edit)** 권한이 있어야 합니다(Account → D1 → Edit).
2. Actions → **Deploy news proxy**를 실행합니다. 배포 전에 D1 `fss-usage`가 없으면 만들고 `wrangler.toml`에 연결하며, 표/인덱스는 첫 요청 때 자동으로 만듭니다. 실행 요약에 관리자 화면 주소(`…/admin`)가 표시됩니다.
3. 관리자 화면(`/admin`)에서 `ADMIN_TOKEN`을 입력하면 일자별 DAU·WAU(7일)·MAU(30일), 버전별 분포, 메뉴별 사용자 수·열린 횟수(최근 7일 일자별 사용자 수 포함)를 볼 수 있습니다. 날짜는 한국 시간 기준입니다. 앱 안에는 관리자 화면을 두지 않습니다(APK의 앱 토큰은 추출될 수 있기 때문).
- 한계: 설치 ID 기준이라 재설치하면 새 사용자로, 한 사람이 여러 기기를 쓰면 각각 집계되며, 통계를 끈 사용자는 빠집니다. D1이 연결되지 않으면 `/usage/ping`은 503을 돌려주고 앱은 조용히 넘어갑니다.

## 웹 버전(fss-insights-web) 접속
웹 버전(PWA, https://hdlee73.github.io/fss-insights-web/)은 브라우저에서 이 서버를 직접 부릅니다. 웹 소스는 공개라 앱 토큰을 넣을 수 없어서, 다음처럼 받습니다(`web-lib.js`).

- `wrangler.toml`의 `WEB_ORIGINS`(기본 `https://hdlee73.github.io`)에서 온 요청만 토큰 없이 받고 CORS 머리글을 붙입니다. 열리는 경로는 `/law`·`/dart`·`/fisis`·`/stats`·`/library`·`/usage/ping`·`/fetch`이고, 네이버 뉴스(`/news`)는 웹에 열지 않습니다.
- IP별로 1분에 600건까지만 받습니다(`WEB_LIMIT` 바인딩). 넘으면 429를 돌려줍니다.
- `/fetch?url=`은 앱이 기기에서 직접 읽던 기관·시세 사이트(금감원·금융위·연구원·BIS·네이버 증권 등, `FETCH_HOSTS`)만 대신 읽고 10분간 캐시합니다. 목록 밖 주소는 403입니다.
- Origin 머리글은 브라우저 밖에서 꾸며 보낼 수 있으므로 완전한 차단은 아닙니다. 남용의 상한은 위 요청 수 제한과 각 Open API의 일일 한도입니다.

설정을 바꾼 뒤에는 Actions → **Deploy news proxy**를 다시 실행해야 웹에서 동작합니다.
