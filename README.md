# 금융뉴스 레이더

국내 금융감독·금융투자회사 관련 기사를 빠르게 모아 시간순으로 확인하고 공유하는 Android 앱입니다. 기존 SwiftUI 뉴스 검색 앱의 핵심 흐름을 Android Jetpack Compose로 옮기면서 검색 건수, 키 관리, 맞춤 키워드, 중복 기사 문제를 개선했습니다.

## 주요 기능

- 최대 5개 감시 키워드를 저장하고 첫 화면에서 통합 피드로 확인
- 키워드·회사명 직접 검색 (검색 실행 시 키보드 자동 닫기)
- `AND`, `OR`, 괄호, 따옴표 문구 검색과 공백 AND 검색
- Google 뉴스와 네이버 뉴스 API 결과를 합치는 통합 검색
- 30대 주요 언론 또는 전체 언론 범위 선택
- 24시간·7일·30일 기간 필터와 날짜별 타임라인
- 언론사, 게시 시각, 제목, 요약 표시
- 원문 열기, Android 공유 시트(카카오톡 등), 즐겨찾기
- 기사 제목 전체를 기준으로 한 보수적인 중복 제거
- 검색 결과에서 수집·표시·중복 제외·언론 범위 제외 건수를 구분해 표시
- 금감원·검사·제재·내부통제 등 복수의 감독 키워드가 겹친 기사는 `감독 핵심`으로 표시
- 네이버 검색 사용 시 100건씩 최대 1,000번째 결과까지 추가 로딩

## 화면 구성

작은 제목과 검색창, 빠른 키워드, 현재 필터 요약만 기본으로 표시합니다. ‘필터’를 누르면 검색 방식·언론 범위·기간을 변경하고 검색식 안내를 볼 수 있습니다. 검색을 실행하면 필터와 키보드가 닫힙니다.

검색 영역과 기사 목록이 함께 스크롤되므로 뉴스를 읽는 동안 상단 조작부가 올라가고 목록이 화면을 넓게 사용합니다. 결과 집계는 눌러 펼칠 수 있고, 기사 상단의 북마크·공유 버튼을 사용할 수 있습니다. 기존 민트·살구 파스텔 색상과 AND·OR·괄호·문구 검색을 유지합니다.

## 검색 방식

앱은 세 가지 방식을 지원합니다.

1. **통합 검색**: 기본 방식입니다. Google 뉴스와 네이버 뉴스 API 결과를 합칩니다. 네이버 키가 없으면 Google 뉴스만 사용하고 앱은 정상 작동합니다.
2. **바로 검색**: 별도 키 없이 Google 뉴스 RSS를 사용합니다. 맞춤 피드는 각 저장 키워드의 원문 검색을 최대 100건까지 유지하면서 금융감독 확장 검색을 추가로 병합합니다.
3. **네이버 심층 검색**: 사용자가 발급받은 Naver Client ID와 Client Secret을 앱 설정에 입력합니다. 공식 뉴스 검색 API의 `start` 페이지를 이동해 한 번의 100건 제한을 넘어 최대 1,000건까지 확인합니다.

Boolean 검색은 OR 분기를 각각 별도 검색으로 실행한 뒤 결과를 합칩니다. 예를 들어 `금감원 AND (증권사 OR 자산운용사)`는 `금감원 증권사`와 `금감원 자산운용사`를 각각 검색합니다. 공백은 AND로 처리하며 `"내부 통제"`처럼 따옴표로 문구를 묶을 수 있습니다.

API 키는 소스와 APK에 포함되지 않습니다. 앱에서 입력한 값은 Android Keystore 기반 AES-GCM으로 암호화해 해당 기기에만 저장합니다.

새 설치의 기본 언론 범위는 `전체 언론`, 검색 방식은 `통합 검색`입니다. 이전 버전에서 선택해 저장한 설정은 업데이트 후에도 유지됩니다.

## 30대 언론 기준

통신·방송 11곳, 종합지 10곳, 경제지 9곳을 포함합니다.

`연합뉴스, 뉴시스, 뉴스1, KBS, MBC, SBS, YTN, JTBC, TV조선, MBN, 채널A, 조선일보, 중앙일보, 동아일보, 한겨레, 경향신문, 한국일보, 서울신문, 세계일보, 국민일보, 문화일보, 매일경제, 한국경제, 서울경제, 머니투데이, 이데일리, 아시아경제, 헤럴드경제, 파이낸셜뉴스, 디지털타임스`

이는 앱의 편집 기준이며 공식 순위가 아닙니다. 전체 언론을 선택하면 이 필터를 적용하지 않습니다.

## 개발 및 빌드

필요 환경:

- JDK 17
- Android SDK 36
- Gradle wrapper 포함

```bash
./gradlew testDebugUnitTest
./gradlew assembleRelease
```

설치 가능한 APK는 `app/build/outputs/apk/release/app-release.apk`에 생성됩니다. GitHub Actions도 같은 테스트와 빌드를 실행하고 APK를 아티팩트로 보관합니다.

## 배포 서명

현재 공개 APK는 직접 설치와 기능 검증을 위한 공개 시험 키로 서명됩니다. 이 키는 저장소에 공개되어 있으므로 신뢰 가능한 정식 배포 서명으로 사용할 수 없지만, v0.2.0 이후 시험 버전끼리는 설정과 북마크를 유지하며 업데이트할 수 있습니다. Play 스토어 배포 전에는 별도의 비공개 release keystore를 안전한 비밀 저장소에서 관리해야 합니다.

## 데이터 제공 관련

앱은 기사 제목·요약·링크만 표시하고 기사 본문을 복제하지 않습니다. 실제 서비스 운영 시 Google 뉴스 및 네이버 API의 최신 이용 조건과 각 언론사의 링크·콘텐츠 정책을 확인하세요.
